## 📖 About The Project

**Zaitoun** is a modern, multi-section website developed to practice and demonstrate front-end development skills using **HTML5 and CSS3**.

The project focuses on responsive layouts, reusable design patterns, CSS animations, interactive hover effects, and visually appealing components. It combines a variety of website sections into one cohesive interface with a consistent color scheme and carefully organized styling.

The website serves as a practical demonstration of front-end development concepts, from fundamental page structure to more advanced CSS layout and animation techniques.

## ✨ Key Features

- 📱 **Responsive Design** — Layout adaptations for desktop, tablet, and mobile screens.
- 🧭 **Navigation Bar** — Clean navigation with animated hover indicators.
- 📂 **Mega Menu** — Organized dropdown navigation with section links.
- 🚀 **Animated Landing Section** — Hero layout with a floating illustration.
- 📰 **Articles Section** — Content cards with hover transitions and animated arrows.
- 🖼️ **Interactive Gallery** — Image zoom, rotation, and visual hover effects.
- ⭐ **Features Section** — Distinct feature cards with themed colors and animated buttons.
- 💬 **Testimonials** — Review cards with profile images and star ratings.
- 👥 **Team Members** — Profile cards with social icons and grayscale hover effects.
- 🛠️ **Services Section** — Service cards with CSS-generated numbering.
- 📊 **Skills Section** — Visual skill indicators with percentage-based progress bars.
- ⚙️ **How It Works** — Structured process cards with interactive backgrounds.
- 📅 **Events Section** — Event information, countdown-style display, and subscription form layout.
- 💎 **Pricing Plans** — Pricing cards with a highlighted popular plan.
- 🎬 **Top Videos** — Video list layout with a preview image.
- 📈 **Statistics Section** — Stat cards with animated borders and background imagery.
- 🎁 **Discount Section** — Split-screen layout, changing background images, and a request form.
- 🦶 **Detailed Footer** — Social links, navigation links, contact details, and image gallery.

## 📱 Responsive Design

The stylesheet uses CSS media queries and a responsive container system to adapt the layout to different screen sizes.

The main container breakpoints are:

| Minimum Screen Width | Container Width |
|---|---:|
| 768px | 750px |
| 992px | 970px |
| 1200px | 1170px |

Additional media queries adjust navigation, images, forms, and section layouts for smaller screens.

## 🎨 Design System

The project uses a consistent visual foundation defined through CSS custom properties.

```css
:root {
  --main-color: #2196f3;
  --main-color-alt: #2bf6e0;
  --transition: 0.3s;
  --p-color: #666;
  --padding: 100px 0;
  --section-background-color: #ececec;
}
```

**Design highlights:**

- Primary blue accent with a turquoise secondary accent.
- Reusable spacing and transition settings.
- Card layouts with shadows, borders, and hover elevation.
- Decorative section headings and geometric backgrounds.
- Smooth scrolling between page sections.
- CSS animations for movement and interaction feedback.
