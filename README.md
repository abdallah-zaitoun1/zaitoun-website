## ✨ About The Project

**Zaitoun** is a modern website project designed to showcase a clean user interface, responsive layouts, and engaging visual effects using HTML and CSS.

The project focuses on practical front-end development skills, reusable styling patterns, and creating a consistent experience across different screen sizes.

## 🚀 Features

- 🎨 Modern and visually appealing design
- 📱 Responsive layouts for mobile, tablet, and desktop
- 🧭 Interactive navigation with a mega menu
- 📰 Articles and gallery sections
- ⭐ Features and testimonials sections
- 👥 Team members and services sections
- 📊 Skills and statistics sections
- 💰 Pricing plans and discount section
- 🎬 Videos section
- ✨ CSS transitions, hover effects, and animations
- 🧩 Reusable CSS variables and organized stylesheets
- 📐 Layouts built with Flexbox and CSS Grid

## 🛠️ Built With

| Technology | Purpose |
| --- | --- |
| HTML5 | Semantic page structure |
| CSS3 | Styling, layouts, and visual effects |
| Flexbox | Flexible one-dimensional layouts |
| CSS Grid | Structured multi-column layouts |
| Media Queries | Responsive design |
| CSS Animations | Motion and visual interactions |
| Font Awesome | Icons |
| Google Fonts | Typography |

## 📱 Responsive Design

The website uses CSS media queries and responsive container widths to adapt to different devices.

| Breakpoint | Container Width |
| --- | ---: |
| Small devices | Fluid |
| 768px and above | 750px |
| 992px and above | 970px |
| 1200px and above | 1170px |

## 🎨 Design Highlights

- CSS custom properties for consistent colors and spacing
- Smooth transitions and hover interactions
- Pseudo-elements for decorative effects
- Keyframe animations for selected elements
- Flexbox and Grid for flexible layouts
- Consistent typography and spacing

## 💻 Getting Started

### 1. Clone the repository

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/zaitoun-website.git
```

### 2. Open the project

```bash
cd zaitoun-website
```

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
